# Almore Landing Page

PROMPT — LANDING PAGE ALMORE INTELIGÊNCIA CONTÁBIL

Crie uma landing page completa, responsiva e profissional para a Almore Inteligência Contábil, uma empresa de contabilidade 100% digital com posicionamento consultivo e atendimento ágil. O objetivo da página é apresentar a marca e captar leads via formulário.

DESIGN SYSTEM

Cores:

Bordeaux principal: #7C1638

Bordeaux escuro: #68112F

Cinza médio: #818181

Cinza escuro: #595959

Fundo claro (seções claras): #F5F3F0

Branco: #FFFFFF

Texto principal em seções escuras: #FFFFFF

Texto principal em seções claras: #1A1A1A

Tipografia:

Títulos/display: Montserrat (Google Fonts), weight 700–800, letra maiúscula ou sentence case conforme seção

Corpo/texto corrido: Inter (Google Fonts), weight 400–500

Labels/eyebrows de seção: Montserrat, weight 600, letter-spacing 0.12em, uppercase, tamanho pequeno (12–13px)

Estética geral:

Premium, limpa, direta. Sem decoração excessiva.

Alternância entre seções escuras (bordeaux) e claras (off-white/branco)

Border-radius sutil nos cards: 12px

Sombras leves nos cards em seções claras: box-shadow: 0 2px 16px rgba(0,0,0,0.07)

Sem ícones genéricos de stock — use apenas numeração ou marcadores tipográficos simples

COMPORTAMENTOS GERAIS

Scroll suave em todos os links e CTAs internos

Animações de entrada: elementos entram com fade-in + translate-y leve (12px → 0) conforme o usuário rola a página. Usar IntersectionObserver ou CSS scroll-driven. Nada exagerado.

Responsivo: mobile-first. Em mobile, todos os grids viram coluna única, headline display reduz para ~36–40px, paddings laterais 20px.

Formulário: validação básica dos campos obrigatórios (nome, e-mail, telefone). Mensagem de erro inline discreta.

Hover nos botões: leve escurecimento do fundo (bordeaux mais escuro) com transição 200ms.

Hover nos cards: elevação sutil da sombra, transição 200ms.

OBSERVAÇÕES FINAIS

Não usar imagens de stock de pessoas. A página é 100% tipográfica e de composição.

Não usar ícones SVG genéricos — apenas marcadores tipográficos (✓, números, traços).

Todo o copy já está definido neste prompt — não inventar texto adicional.

As fontes Montserrat e Inter devem ser carregadas via Google Fonts.

O formulário não precisa ter backend real — apenas o estado visual de sucesso após envio.
